— Under the Hood —

How the AI Model Works

🧠
Step 01

Three dlib Models

A HOG face detector finds bounding boxes, a shape predictor maps 68 facial landmarks, and a recognition model converts those landmarks into a 128-dimensional embedding vector — a unique numerical fingerprint for every face.

📝
Step 02

One-Time Registration

When a student registers, their photo is run through the pipeline and the resulting 128-d vector is stored in the database as their face embedding. This only happens once.

⚙️
Step 03

SVM Classifier Training

All stored embeddings are loaded and used to train a Linear SVM — each student ID is a class. The model is cached per session and re-trained automatically whenever a new student registers.

🔍
Step 04

Two-Stage Attendance Prediction

Every face in a classroom photo goes through two checks before being marked present:

Stage 1 — SVM Nomination

The SVM predicts which student the face belongs to with a confidence score. Faces below 45% confidence are rejected immediately.

→
Stage 2 — Distance Verification

The embedding is compared against all stored embeddings using L2 distance. Only faces within a distance of 0.55 are marked present.

Key Thresholds

ThresholdValuePurpose
SVM Confidence0.45Reject uncertain SVM nominations
L2 Distance0.55Reject faces too far from stored embeddings
Upsample Factor2×Detect smaller or distant faces in classroom photos
